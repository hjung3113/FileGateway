# Server Access Core

## 역할

`Server Access Core`는 로그에 한정되지 않는 공통 서버/파일 접근 계층이다.

## 책임

- 설비 또는 논리 대상에 대한 실제 서버 정보 획득
- MSSQL 기준정보 접근 추상화
- 원격 파일 목록 조회
- 파일 존재 여부 확인
- 파일 크기 및 기본 메타데이터 조회
- 파일 스트림 열기
- 공통 예외 및 접근 실패 처리

## 비책임

다음 로직은 Core에 넣지 않는다.

- 로그 종류 판단
- 시간별/일별 로그 필터링
- 갱신형 로그 정책
- 로그 파일명 규칙
- 특정 Provider만 사용하는 업무 규칙

## 외부 노출 금지 정보

Core에서 얻은 다음 값은 원칙적으로 클라이언트 응답에 직접 노출하지 않는다.

- 실제 서버명/IP
- UNC 또는 로컬 물리 경로
- DB 내부 식별자
- 공정/서버 분산 구조

## 오류 구분

최소한 다음 상황을 구분할 수 있어야 한다.

- 기준정보 없음
- 서버 대상 해석 실패
- 기준정보는 있으나 경로가 존재하지 않음
- 서버/공유 경로 접근 권한 실패
- 파일이 조회 후 삭제/변경됨
- 스트리밍 중 I/O 실패

이 구분은 외부 오류 코드 정책 확정 시 논리 오류로 매핑한다.
