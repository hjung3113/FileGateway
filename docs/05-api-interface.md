# API / 클라이언트 인터페이스

## 전송 방식

- HTTP/HTTPS
- 메타데이터: JSON
- 파일 본문: Streaming Download

## 클라이언트 대상

- .NET
- Python / FastAPI
- Windows / Linux

## 인터페이스 방향

클라이언트 SDK/Wrapper는 익숙한 FTP 라이브러리의 사용 패턴을 차용한다.

예시 개념:

- `GetListing(...)` / `nlst(...)`
- `FileExists(...)`
- `GetFileSize(...)` / `size(...)`
- `DownloadFile(...)` / `retrbinary(...)`

단, 실제 프로토콜은 FTP가 아니며 다음 개념은 노출하지 않는다.

- `cwd`
- Passive/Active mode
- 실제 디렉터리 이동
- 실제 서버 주소
- 물리 파일 경로

## 논리 API 기능

### 목록 조회

입력:

- 설비명
- 시작 일시(선택)
- 종료 일시(선택)
- 로그 종류(선택)

출력:

- 논리 파일 ID
- 파일명
- 로그 종류
- 생성/기준 시각
- 파일 크기
- 갱신형 여부 등 필요한 메타데이터

### 파일 정보 조회

- 존재 여부
- 크기
- 필요한 최소 메타데이터

### 다운로드

- 논리 파일 ID 기반 요청
- 서버/경로를 다시 해석한 후 스트리밍
- 물리 경로는 응답에 포함하지 않음

## API 안정성 원칙

서버 재배치, 경로 변경, 공정 구조 변경이 클라이언트 인터페이스 변경으로 이어지지 않아야 한다.
