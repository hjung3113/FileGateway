# Log Provider

## 역할

`Log Provider`는 설비 로그 제공에 필요한 업무 규칙을 담당하고, 실제 파일 I/O는 `Server Access Core`에 위임한다.

## 입력

- 설비명
- 선택적 시작 일시
- 선택적 종료 일시
- 선택적 로그 종류

## 처리 흐름

1. 설비명으로 기준정보 조회
2. 설비와 연결된 서버 및 로그 종류별 경로 정보 획득
3. 로그 종류별 조회 정책 적용
4. Server Access Core를 통해 실제 파일 목록 확인
5. 클라이언트용 논리 파일 목록 생성
6. 선택된 파일 다운로드 시 스트리밍 요청 전달

## 로그 조회 정책

### 시간 단위 생성 로그

- 특정 일자 조회 가능
- 특정 시간 조회 가능
- 시작/종료 일시 범위 조회 가능

### 일 단위 생성 로그

- 특정 일자 조회 가능
- 일자 범위 조회 가능

### 계속 갱신되는 로그

- 날짜/시간 필터를 적용하지 않는다.
- 현재 존재하는 해당 종류의 파일을 그대로 목록에 포함한다.

## 설계 원칙

- 생성 주기 및 필터 정책은 가능하면 기준정보로 관리한다.
- 파일명/경로 규칙을 Provider 내부에 과도하게 하드코딩하지 않는다.
- 물리 서버와 경로를 외부 응답에 노출하지 않는다.
- 목록 조회 결과에는 다운로드에 사용할 논리 식별자를 제공한다.
