기본 저장 위치는 sessionStorage이며, 체크하면 localStorage로 이동합니다.

1. 설비 제공 파일 종류

2. 로그

목록과 조건 기반 직접 다운로드는 같은 조건을 사용합니다.

속성 필터 (attr.<name>=<value>)

3. 파일 공통

fileId로 metadata 조회/다운로드 — GET /api/v1/files?fileId=...

4. Current Configuration
